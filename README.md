# AI-Driven-Telangana-Health-Chatbot

**Overview**

The AI-Driven Telangana Public Health Chatbot is a multilingual healthcare assistant designed to improve health awareness among rural and semi-urban populations. It provides instant information about disease symptoms, preventive healthcare, vaccination schedules, and district-based outbreak alerts.

The system is built using Python, FastAPI, Streamlit, and SQLite. It offers a user-friendly chat interface and supports multiple languages, making healthcare information accessible to a wider audience.

**Key Features**
🩺 Disease symptom awareness
💉 Vaccination schedule information
🚨 District-wise outbreak alerts
🌍 Multilingual support (English, Hindi, Telugu)
💬 Interactive chatbot interface
🗄️ Local data storage using SQLite
🏛️ Government-style health alert dashboard
